# download-speed

Консольный скрипт на Node.js для замера скорости скачивания.
Делает **10 последовательных запросов** к указанному адресу, каждый раз дочитывает ответ
до конца, затем выводит среднее время запроса, общий объём скачанного и скорость.

Внешних зависимостей нет. Нужен Node.js 18+ (используется встроенный `fetch`).

## Запуск

```bash
node download-speed.mjs https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

или через npm:

```bash
npm start -- https://example.com/big-image.jpg
```

## Пример вывода

```
URL: https://example.com/big-image.jpg
Запросов: 10 (последовательно)

# 1       5.24 МБ     0.612 с
# 2       5.24 МБ     0.431 с
...
#10       5.24 МБ     0.428 с

Итого:
  Среднее время запроса: 0.455 с
  Общий объём:           52.40 МБ
  Скорость скачивания:   92.13 Мбит/с (11.52 МБ/с)
```

## Единицы измерения

| Величина      | Единица    | Определение                          |
|---------------|------------|--------------------------------------|
| Время         | секунды, с | —                                    |
| Объём         | МБ         | 1 МБ = 1 000 000 байт (десятичный)   |
| Скорость      | **Мбит/с** | 1 Мбит = 1 000 000 бит               |
| Скорость (доп.) | МБ/с     | 1 МБ/с = 1 000 000 байт в секунду    |

Основная единица скорости — **мегабиты в секунду**: в ней указывают скорость тарифы
провайдеров и сервисы вроде speedtest, поэтому результат удобно сравнивать.
В скобках дана та же скорость в мегабайтах в секунду (1 МБ/с = 8 Мбит/с).

## Как считается

- **Время запроса** — от отправки запроса до получения последнего байта тела ответа.
  Включает DNS, установку соединения, TLS и ожидание первого байта.
- **Среднее время** — сумма времени 10 запросов / 10.
- **Общий объём** — сумма байт тела всех 10 ответов.
- **Скорость** — общий объём / общее время всех запросов (а не среднее из 10 скоростей,
  чтобы короткие запросы не искажали результат).

Запросы отправляются с заголовками `Accept-Encoding: identity` (без сжатия — считаются
реальные байты файла) и `Cache-Control: no-cache` (просьба не отдавать ответ из
промежуточных кэшей). Редиректы проходятся автоматически.

## Ошибки

Если URL не передан, некорректен, сервер вернул код не из диапазона 2xx или запрос
упал по сети — скрипт пишет причину в stderr и завершается с кодом 1.
